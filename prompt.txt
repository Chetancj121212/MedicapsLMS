Medicaps University ECE Online Course Platform

Build a minimal, modern Learning Management System (LMS) prototype for the:

Department of Electronics Engineering
Medicaps University, Indore

The platform will provide structured online courses containing video lecture series, modules/chapters, quizzes, progress tracking, course completion, and digitally verifiable certificates.

The application should feel like an official university academic platform rather than a generic SaaS dashboard.

3. DEPLOYMENT REQUIREMENT

The frontend will eventually be hosted on:

Netlify

Videos should NOT be stored in cloud storage.

For the prototype:

Video files are uploaded/maintained locally.
The application stores the video path/URL in the database.
The video player fetches the video from the configured video location.
Do not integrate AWS S3, Cloudinary, Firebase Storage, Vimeo, YouTube, etc.

Important:

Design a small storage abstraction so that video storage can later be changed without rewriting the course system.

Example conceptual structure:

VideoStorage
    ├── LocalStorage
    └── FutureCloudStorage

The current implementation should use local video storage.

18. QUIZ PASSING REQUIREMENT

For this prototype:

Passing percentage = 100%

This means the student must answer every question correctly.

After passing:

✓ Quiz Passed

Module 2 completed.

Module 3 is now unlocked.

Make the passing percentage configurable per quiz so the system can later support 60%, 70%, 80%, etc.

19. FINAL COURSE COMPLETION

A student receives course completion only when:

All required lectures completed
        +
All required module quizzes passed
        +
Final assessment passed at 100%

Then:

Course Status = COMPLETED

Record:

completed_at

Once completed, the course remains completed even if the student later revisits content.

45. CERTIFICATE GENERATION LOGIC

When final completion requirements become true:

checkCourseCompletion(studentId, courseId)

if:
    allRequiredLecturesCompleted
    AND allRequiredQuizzesPassed
    AND finalQuizPassed
then:

    if certificate does not already exist:

        generate unique certificate number

        create certificate record

        generate PDF

        generate QR code

        save certificate

        return certificate

If certificate already exists:

return existing certificate

Do not generate duplicate certificates for repeated visits.
